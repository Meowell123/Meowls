# Meowlsinstaller 🐱🛠️

The official installer for **Meowls**—a fast, customizable alternative to the Windows `dir` command.

## 🚀 Installation

Open your Windows **Command Prompt** (`cmd.exe`) and run this single command to download and launch the installer:

```cmd
curl https://raw.githubusercontent.com/Meowell123/Meowlsinstaller/refs/heads/main/MINST.cmd -O && MINST.cmd
```

## 🧹 Uninstallation

To remove Meowls from your computer and cleanly purge it from your system's environmental `PATH`, run:

```cmd
curl https://raw.githubusercontent.com/Meowell123/Meowlsinstaller/refs/heads/main/UNINST.cmd -O && UNINST.cmd
```
